# Extra countries

Code Armour provides automated technical checks and general compliance information. It does not provide legal advice, certify compliance, guarantee security or identify every possible risk. Results may be incomplete or incorrect. Users remain responsible for testing their websites, reviewing applicable requirements and obtaining professional advice where appropriate.

Each file is general notes, mostly from secondary sources, not a complete statement of the law.

One file per country, researched on demand by the skill with `templates/country-research.md` when a user is in (or has users in) a country the main files don't cover. Name: `<country>.md`, e.g. `poland.md`. These are checked less thoroughly than the main files: treat every line as ❓ until a human or a second check confirms it.

Contributions welcome: a pull request to github.com/AlonAI4/code-armour adds a country for everyone.
